## Project: baby-arb-ke

US-to-Kenya arbitrage pipeline for used baby items. Source from US
marketplaces based on Kenyan demand signals, route through a US
consolidator, and resell at margins that net 30%+ after all costs.

## Domain knowledge

The business: source used baby items from US sellers (eBay primary),
ship to Nairobi via consolidator, resell on Jiji and own storefront.
Margin floor 50% gross. Target net margin 30-35%. Target sell-through
under 45 days. Never buy a recalled item or expired car seat.

The stack: Python 3.11+, Poetry, pytest, FastAPI, SQLite (dev) /
Postgres (prod), httpx, pydantic, sqlmodel, structlog, typer.

The markets: eBay US (Browse + Buy APIs), Mercari/FB/OfferUp (scraped
via Apify or Bright Data), Jiji.co.ke (KE used market), Jumia/Kilimall
(KE retail reference), Facebook parenting groups (KE demand signal).

The money: Wise Business + virtual cards per buy task (per-merchant
limits, exact-amount, single-use). Telegram one-tap approval for
buys above $200. M-Pesa Daraja for KE buyer payments.

The risk: returns, damage, dead inventory, recalls. Budget 10-15% of
buys to go wrong. Margin discipline is the only thing that makes the
business work.

## Commit discipline

Format: `<type>(<scope>): <description>`
Types: `feat | fix | docs | test | refactor | perf | chore | ci | data | eval | sourcing | pricing`
Branch: `task/<slug>` — never push to main
PR: always open for human review
Changelog: auto-generated by commitizen

Custom types unique to this project:
- `sourcing`: scraper, search client, listing parser changes
- `pricing`: landed-cost formula, margin rules, FX changes

Examples:
```
pricing(landed-cost): add KEBS PVoC fee to CIF calculation
sourcing(ebay): handle item-not-shippable-internationally edge case
compliance(recall): refresh CPSC cache before every check
data(fixtures): add 12 stroller listings for pricing tests
```

## Hard constraints

- **Never buy a recalled item.** Compliance Checker has veto.
- **Never buy a car seat older than 6 years from manufacture.**
- **Never override the 50% margin floor.** No "this one is special".
- **Never auto-buy above $200.** Telegram approval required.
- **Never push to main.** Branch + PR always.
- **Never push without a PASS gate record.** Run scripts/pre_push.sh; no --no-verify.
- **Never fabricate market data.** Unavailable source → UNKNOWN with a reason, not demo values.
- **Never invent KE retail prices.** If no source, mark UNKNOWN and abstain.
- **Never store credentials in repo.** Env vars only, gitignored .env.
- **Never set status: approved on a buy candidate.** Human gate.
